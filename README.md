## 💻 Установка

### 🪟 Windows
1. Установи **Python 3.12.x** → https://www.python.org/downloads/release/python-3120/
   > ⚠️ Отметь галочку **«Add Python to PATH»**
2. Скачай бота (**Code → Download ZIP**) и распакуй
3. Запусти **`Setup.bat`** — установит окружение и зависимости
4. Запусти **`start.bat`**
5. Заверши настройку по ссылке из терминала

### 🍎 macOS
1. Установи Python 3.12:
   ```bash
   brew install python@3.12
   ```
2. Скачай и распакуй бота
3. В Терминале:
   ```bash
   chmod +x install.sh && ./install.sh
   ```
4. Запуск:
   ```bash
   source venv/bin/activate && python bot.py
   ```

### 🐧 Linux (Ubuntu 22/24)
1. Установка:
   ```bash
   chmod +x install.sh && ./install.sh
   ```
2. Если нужен Python:
   ```bash
   sudo apt update && sudo apt install python3.12 python3.12-venv -y
   ```
3. Запуск:
   ```bash
   source venv/bin/activate && python bot.py
   ```
