## Установка

### Windows

1. Установите **Python 3.12.x** (галочка **«Add Python to PATH»** при установке).
2. Скачайте архив бота (кнопка **Code → Download ZIP** на GitHub) и распакуйте.
3. Запустите **`Setup.bat`** — он создаст виртуальное окружение и установит зависимости.
4. После установки запускайте бота через **`start.bat`**.
5. Завершите настройку по ссылке из терминала.

### macOS

1. Установите **Python 3.12.x** (рекомендуется через Homebrew):
   ```bash
   brew install python@3.12
   ```
2. Скачайте бота и распакуйте в удобную папку.
3. В Терминале зайдите в папку бота и запустите установку:
   ```bash
   chmod +x install.sh
   ./install.sh
   ```
4. Запустите бота:
   ```bash
   source venv/bin/activate
   python bot.py
   ```
5. Завершите настройку по ссылке из терминала.

### Linux (Ubuntu 22/24)

1. Установка из папки бота:
   ```bash
   chmod +x install.sh
   ./install.sh
   ```
2. Если установщик ругается на Python — поставьте его вручную:
   ```bash
   sudo apt update && sudo apt install python3.12 python3.12-venv -y
   ```
3. Запуск:
   ```bash
   source venv/bin/activate
   python bot.py
   ```

## Первая настройка

При первом запуске бот попросит:

1. **Токен Telegram-бота** — получите у [@BotFather](https://t.me/BotFather) (команда `/newbot`).
2. **Пароль** — придумайте пароль для входа в управляющего бота.
3. Откройте своего Telegram-бота, введите `/start` и пароль.
4. **Cookies аккаунта Playerok** — бот подскажет, как их получить (раздел «Аккаунт»).

После авторизации всё управление — через кнопки в Telegram.
